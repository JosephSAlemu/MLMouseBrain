- All function/method comments must be done with single quote marks 
(ex: '''
     does <blank>
     ''')

- All function/method comments must have an Args and Returns explaining parameters and what it returns (if needed)
(ex: '''
     Args:
          thread_chunk_tuple: tuple of thread start index and stop index

     Returns:
          None
     ''')

- All strings must have double quotations.

- No hardcoded paths. Must either be a parameter for a field for a class.

- One space between before and after each function.

- Type hints in the signature of all functions.
